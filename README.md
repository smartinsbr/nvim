
## Requirements
- Install to the latest version of node
- Install ripgrep (choco install ripgrep) 
- Install fd (choco install fd)
- Make sure Python 3.9+ is available in your $PATH
- Install the module: python3 -m pip install --user --upgrade pynvim
- Install LuaRocks: https://github.com/luarocks/luarocks/blob/main/docs/installation_instructions_for_windows.md

### Remarks
- Consider using Windows with WSL to install neovim
